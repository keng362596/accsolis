# AccSolis Landing Page

This repository contains a static landing page that can be hosted on GitHub Pages without needing any backend or server.

## Files

- `index.html` — main landing page markup
- `styles.css` — page styling
- `script.js` — small script for footer year

## GitHub Pages deployment

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to **Pages**.
4. Choose **Deploy from a branch** and select the `main` branch.
5. Use the root folder (`/`) as the publishing source.

The page will be available as a static website with no server required.
